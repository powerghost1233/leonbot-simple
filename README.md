# LeonBot PRO — modo silencioso `#linea`

El bot no responde a saludos, preguntas ni mensajes normales.

Solo se activa cuando el mensaje empieza por:

```text
#linea
```

## Comandos

Mostrar instrucciones:

```text
#linea
```

Consultar una línea:

```text
#linea TUUSUARIO
```

Solicitar renovación:

```text
#linea renovar TUUSUARIO
```

Contratar una línea nueva:

```text
#linea contratar
```

Duraciones:

```text
#linea contratar 1
#linea contratar 3
#linea contratar 6
#linea contratar 12
```

El panel conserva la renovación automática de un mes, la fecha manual y el aviso al cliente.
